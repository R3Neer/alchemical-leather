# Temporary requirements — Leatherworker infusion trades

Status: implementation working document; delete before merge/release.

## Functional requirements

- Keep vanilla Leatherworker levels I–III unchanged: no infused armor trades before Expert.
- Expert (IV) adds exactly one Alchemical Leather trade candidate. It may generate only dyeable humanoid LEGS or FEET armor, never HEAD, CHEST or BODY. Infusions are timed and level I only (amplifier 0).
- Master (V) adds exactly two Alchemical Leather trade candidates: one advanced timed trade and one persistent trade.
- Master timed may generate dyeable humanoid HEAD/CHEST/LEGS/FEET armor or explicitly trade-enabled BODY/animal armor. Maximum potion level is II (amplifier <= 1). Level III is never sold.
- Master persistent may generate the same Master item categories, including chestplates and BODY/animal armor. It uses stable infusion mode, maximum level I (amplifier 0), exactly one use, and requires Dragon's Breath as a non-discountable second cost.
- Reorientation (`clinging_reoriented:reorientation`) is never a villager-trade option at any tier, even if datapacks attempt to add it.
- Any persistent effect from namespace `scalebrews` must be level I (amplifier 0). More generally, persistent trades never exceed amplifier 0.
- Scale Brews level III is never sold. Default Scale Brews participation is Master-only because Growth/Shrinking are chest-slot effects and BODY armor is Master-only.
- Default persistent pool excludes Invisibility, Turtle Master, instantaneous effects, negative/debuff effects, Wind Charged, Oozing, Infested and Weaving. The default pool should favor useful sustained equipment effects.
- Clinging may participate at Master; Reorientation may not.
- Infused trade results are unenchanted, carry the correct Alchemical Leather component (`infusion` for humanoid, `animal_infusion` for BODY), and use potion-derived dye color.
- Reinfusion/cauldron semantics are not changed.

## Economy and probability requirements

- Do not replace or remove vanilla Leatherworker trades.
- Add one candidate to Expert and two candidates to Master while retaining vanilla TradeSet amount = 2.
- Expected default selection probabilities therefore remain: Expert Alchemical trade 2/3; each Master Alchemical category 1/2; at least one Master Alchemical category 5/6; both 1/6.
- Trade prices should be comparable to high-level Armorer equipment, not ordinary cheap dyed leather.
- Expert target price range: 10–14 emeralds, max uses 3.
- Master timed target price range: 16–28 emeralds, max uses 2.
- Master persistent target price range: 28–40 emeralds + 1 Dragon's Breath, max uses 1.
- Variant-specific emerald premiums may be carried through `DataComponents.ADDITIONAL_TRADE_COST`, which vanilla `VillagerTrade` folds into the first cost while leaving the second item cost undiscounted.

## Data/compatibility requirements

- Mechanical dyeability and villager economy eligibility are separate concepts. Being infusible must not automatically make an item sellable by Leatherworkers.
- Use explicit item tags for Expert/Master tradeable armor. Default vanilla Master animal armor includes leather horse armor and wolf armor.
- Use explicit potion tags per tier/slot so datapacks and optional mods can opt in without Java dependencies.
- Missing optional mod IDs must not break tag loading or trade generation.
- Runtime validation must still enforce tier, slot and hard-ban invariants even when datapacks extend tags.
- If no valid candidate remains for a trade category, the offer should be omitted rather than emitting invalid equipment.
